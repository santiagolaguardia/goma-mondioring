# Goma · Mondioring Coach V2

## Qué cambia
- Agrega pestaña Coach.
- Muestra un plan diario.
- Incluye el programa semanal.
- Botón “¿Qué entreno ahora?”.
- Objetivos activos con criterio de superación.
- Reglas automáticas de progresión.
- Alertas por rendimiento y falta de trabajo.
- Nuevos campos específicos: avance en posiciones, dependencia del target y calidad de mordida.
- Trabajos auxiliares: llamada bajo drive, mordida técnica/HA y acondicionamiento.
- Conserva la misma clave de almacenamiento de la V1 para mantener tus sesiones previas en el mismo sitio/dispositivo.

## Cómo actualizar tu GitHub Pages
1. Desde la app V1, exportá un backup por seguridad.
2. Descomprimí este ZIP.
3. En el MISMO repositorio de GitHub, reemplazá:
   - index.html
   - app.js
   - styles.css
   - manifest.webmanifest
   - sw.js
   - carpeta icons
4. Confirmá el commit.
5. GitHub Pages publicará la nueva versión.
6. Abrí la URL de la app en Chrome/Safari y actualizá.
7. Si la app instalada sigue mostrando la V1, cerrala completamente y abrila de nuevo. Si todavía no cambia, abrí primero la URL normal en el navegador, actualizá y luego regresá a la app instalada.

## Datos
La app guarda los entrenamientos localmente en tu dispositivo. Exportá backups regularmente.
